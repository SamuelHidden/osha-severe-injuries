# Аналитика OSHA_db в Python

Визуализация и статистический анализ данных из PostgreSQL-базы `OSHA_db`
(SQL-запросы — в `../SQL`).

## Окружение

Python: Homebrew Python 3.14 (`/opt/homebrew/bin/python3.14`), ядро Jupyter `python3`.
Пакеты перечислены в `requirements.txt`; доустановка:

    python3.14 -m pip install --break-system-packages -r requirements.txt

## Подключение к БД

Параметры лежат в `.env` (хост, порт, база, пользователь, пароль). Файл не публиковать.

```python
from src.db import query, run_sql_file

df = query("SELECT * FROM injuries LIMIT 5")
df = query("SELECT COUNT(*) FROM injuries WHERE state = :state", {"state": "TEXAS"})
body_parts = run_sql_file("01_body_parts.sql")   # список DataFrame: [1.1, 1.2, 1.3, 1.4]
```

## Структура

| Папка | Что лежит |
|---|---|
| `notebooks/` | ноутбуки анализа, по темам как в `SQL/01–08` (список ниже) |
| `src/db.py` | подключение к БД, выполнение запросов и SQL-файлов |
| `src/viz.py` | единый стиль графиков, подписи ru/en, сохранение, палитра, `barh_ranked` |
| `src/stats.py` | `num`, χ² с V Крамера, доля с ДИ Уилсона, рейтинг с объединением одинаковых названий |
| `src/labels.py` | русские названия (части тела, источники, виды травм, типы происшествий, отрасли, штаты), разделы OIICS, категории травм, месяцы и сезоны |
| `figures/ru`, `figures/en` | графики с русскими и английскими подписями (PNG 300 dpi + SVG) |
| `tables/` | итоговые таблицы (CSV / XLSX) |

## Ноутбуки

| Ноутбук | SQL | Что внутри |
|---|---|---|
| `01_body_parts` | 1.1–1.4 | части тела, разделы, тяжесть, структура по годам |
| `02_sources` | 2.1–2.7 | Source и Secondary Source: рейтинги, заполненность, разделы, общий рейтинг, пары, группы источников по годам, тяжесть |
| `03_industries` | 3.1–3.5 | секторы, подсекторы, отрасли, ампутации по секторам, доли по годам |
| `04_years_seasons` | 4.1–4.4 | годы (среднее в месяц), тяжесть по годам, месяц × год, секторы (индекс); **сезонность**: месяцы, времена года, STL, сезонные причины (жара, лёд, падения), дни недели |
| `05_events` | 5.1–5.4 | разделы и тяжесть, топ типов происшествий, тип × часть тела, доли по годам |
| `06_nature` | 6.1–6.3 | виды травм, категории и тяжесть, категория × часть тела, категория × тип происшествия, по годам |
| `07_geography` | 7.1–7.4 | штаты, State Plan, тяжесть и отраслевой состав, города, изменение 2015–2019 → 2021–2025 с ДИ |
| `08_scenarios` | 8.1–8.4 | сценарии «происшествие → источник → часть тела», портреты секторов, Парето, концентрация (Джини) |
| `10_nature_by_month` | 6.4 | **типы травм по месяцам**: состав по месяцам, сезонный профиль каждой категории, характерный тип месяца (индекс к обычной доле, остатки χ² с поправкой Бонферрони), проверка на 2016–2023 |
| `09_top5_summary` | — | сводка для презентации: топ-5 частей тела, источников, причин, секторов (кольцо с «остальными» + столбцы; второе кольцо — доли внутри топ-5); изменение секторов и подсекторов 2015 → 2025 (где профилактика помогла, где нужна) |

Каждый ноутбук заканчивается разделом «Выводы». Выполнить все заново:

    for n in notebooks/[01]*.ipynb; do jupyter nbconvert --to notebook --execute --inplace "$n"; done

**Смена редакции OIICS в 2024 году** затрагивает все справочники OIICS: часть кодов источников
(*Floor, n.e.c.* → *Other constructed surface*), видов травм (нет «боли без уточнения»), типов
происшествий; пустой Secondary Source заменён заглушками 990/991. Тренды считаются по укрупнённым
группам или по сопоставимому периоду (2016–2023) — подробности в ноутбуках.
