# Отчёт: интерактивные дашборды

Дашборды по итоговым таблицам анализа (`Analysis/tables`). Это обычные HTML-страницы без внешних библиотек:
чтобы посмотреть, достаточно открыть `index.html` в браузере, интернет не нужен.

| Страница | Что внутри | Таблицы |
|---|---|---|
| [index.html](index.html) | обзор и ссылки на дашборды | — |
| [01_body_parts.html](01_body_parts.html) | KPI, кольцевая диаграмма разделов тела, топ-15 частей тела | `01_1_top_body_parts`, `01_2_body_divisions`, `01_3_severity_by_division` |
| [02_sources.html](02_sources.html) | KPI, топ-15 основных и вторичных источников, разделы источников, группы источников по годам | `02_1_top_sources`, `02_2_top_secondary_sources`, `02_3_secondary_status_by_year`, `02_4_source_divisions`, `02_5_total_mentions`, `02_7_source_groups_by_year`, `04_1_cases_by_year` |
| [03_industries.html](03_industries.html) | KPI, топ-15 секторов и подсекторов, доля ампутаций по секторам, изменение 2024–2025 к 2015–2016 с 95% ДИ | `03_1_sectors`, `03_2_top_subsectors`, `03_4_severity_by_sector`, `09_5_sector_change`, `04_1_cases_by_year`, `04_6_seasons` |

| [05_nature.html](05_nature.html) | KPI, категории и топ-15 видов травм; исследование «какой тип травм преобладает в каком месяце»: характерный тип месяца, тепловая карта (индекс и доля), сезонный профиль каждого типа | `06_1_top_nature`, `06_2_nature_categories`, `10_1_category_month_share`, `10_2_category_peaks`, `10_2_category_rate_index`, `10_3_category_month_index`, `10_3_category_month_resid`, `10_3_month_leaders`, `10_4_robustness` |

Что умеют страницы:

- при наведении — подсказка с английским названием, кодом OIICS и числом случаев;
- на дашборде «Части тела» наведение на раздел в кольце подсвечивает части тела этого раздела в рейтинге (и наоборот);
- у каждого графика есть переключатель «График / Таблица», у тепловой карты типов травм — ещё «Индекс / Доля»;
- светлая и тёмная тема (кнопка справа вверху, по умолчанию — как в системе);
- вёрстка адаптируется под экран телефона.

## PDF-версии

Те же дашборды в PDF лежат в папке [pdf/](pdf/): A4 альбомный, светлая тема, номера страниц внизу.
Файлы: `00_overview.pdf` (обзор), `01_body_parts.pdf`, `02_sources.pdf`, `03_industries.pdf`, `04_seasons.pdf`,
`05_nature.pdf`. В PDF вместо интерактивных элементов подписи, а значения, которые на сайте видны в подсказках,
есть в таблицах `Analysis/tables`.

Пересобрать PDF после обновления данных (нужны Node.js 22+ и Google Chrome; путь к браузеру можно задать
переменной `CHROME`):

```bash
node Report/export_pdf.mjs
```

При печати страницы из браузера (Ctrl/Cmd+P) тоже включается светлая тема и формат A4 альбомный.

## Как обновить данные

После перезапуска ноутбуков пересоберите данные дашбордов, а затем PDF:

```bash
python3 Report/build.py
```

Скрипт использует только стандартную библиотеку Python. Он читает CSV из `Analysis/tables` и записывает
`Report/assets/data.js`. Долю пальцев рук (все коды со словом *finger*) он считает по
`Data/processed/DataBaseFiles`, так же как ноутбук `01_body_parts`.

## Структура

```
Report/
  index.html, 01–05_*.html          страницы дашбордов
  build.py                           сборка assets/data.js из Analysis/tables
  export_pdf.mjs                     экспорт страниц в pdf/ через headless Chrome
  pdf/                               PDF-версии дашбордов
  assets/
    data.js                          данные (генерируется, вручную не редактировать)
    charts.js                        графики: столбцы, кольцо, линии, тепловые карты, изменения с ДИ, подсказки, таблицы
    style.css                        оформление, светлая и тёмная темы
```

Новый дашборд: скопируйте одну из страниц, добавьте нужные таблицы в `build.py` и ссылку в навигацию
(`<nav class="nav">` на каждой странице) и в `index.html`.
