# SQL-запросы к базе OSHA_db

Анализ тяжёлых производственных травм в США (данные OSHA, январь 2015 – ноябрь 2025,
105 996 случаев).

## Подключение

- СУБД: PostgreSQL (localhost:5432), база `OSHA_db`, пользователь `postgres`
- В DBeaver: открыть файл → выбрать подключение `postgres` и базу `OSHA_db`
- `Ctrl+Enter` — выполнить запрос под курсором, `Alt+X` — выполнить весь файл
  (каждый результат откроется в отдельной вкладке)
- Запросы `01–08` только читают данные, база не изменяется

## Структура базы

| Таблица | Что хранит |
|---|---|
| `injuries` | факт-таблица: 1 строка = 1 случай (дата, город, штат, коды) |
| `body_part_lookup` | части тела (Part of Body) |
| `source_lookup` | источники травмы — общий для Source и Secondary Source |
| `event_lookup` | типы происшествий (Event) |
| `nature_lookup` | характер травмы (Nature) |
| `naics_lookup` | отрасли (NAICS 2022) |

`severity_code` — битовая маска: `4` = госпитализация, `2` = ампутация, `1` = потеря глаза
(например, `6` = госпитализация + ампутация). Проверка: `severity_code & 2 > 0`.

### `00_schema.sql`, `00_load.sql` — создание и заполнение базы
Структура таблиц (ключи, ограничения, индексы) и загрузка CSV из `Data/processed/DataBaseFiles`.
Выполнять в пустой базе из корня проекта:

    createdb OSHA_db
    psql -d OSHA_db -f SQL/00_schema.sql

## Особенности данных

- **2025 год неполный** — данные по 30.11.2025; для сравнения лет используйте среднее в месяц.
- **Коды OIICS иерархические** (части тела, источники, типы происшествий): первая цифра = раздел.
  В данных смешаны редакции OIICS, поэтому одно название может встречаться под разными кодами,
  а с 2024 года часть кодов изменилась — для трендов надёжнее укрупнённые разделы.
- **NAICS**: ~10% кодов из старых редакций (в справочнике — `Not in 2022 NAICS (legacy code)`),
  поэтому отрасли сравниваются по префиксу кода (сектор / подсектор).
- **Secondary Source**: у 52% случаев не указан (NULL), ещё у 7% — заглушки 990/991.
- **География** — абсолютные числа без учёта численности работников; штаты с собственными
  программами охраны труда (State Plan, например California) представлены неполно.
